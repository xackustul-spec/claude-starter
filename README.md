# claude-starter

Набор инструкций для Claude Code: кладётся в новый или работающий проект, после чего Claude
сам разбирается в проекте, задаёт нужные вопросы, подбирает библиотеки и инструменты,
проверяет свои изменения и ведёт документы проекта.

## Установка
Откройте Claude Code в папке проекта и напишите:

    Установи набор https://github.com/xackustul-spec/claude-starter — инструкция в INSTALL.md

Дальше Claude всё сделает сам и спросит, что нужно. Подробно — STARTER.md.
Оценить без установки — запрос из AUDIT-PROMPT.md.
