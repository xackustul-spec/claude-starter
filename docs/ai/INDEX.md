## Указатель документов (docs/ai)
<!-- Claude ведёт сам и молча: новый документ или его часть → строка здесь сразу. Предел — 60 строк. -->
| Файл | Какие данные | Когда читать |
|---|---|---|
| PROFILE.md, STATE.md, LESSONS.md, INDEX.md | паспорт и профиль; сейчас и следующий шаг; уроки; этот указатель | подключены — не открывать |
| KNOWLEDGE.md | договорённости, термины, факты, найденные ответы (мелкие темы) | по надобности: искать здесь раньше, чем спрашивать владельца |
| PROJECT_MAP.md | где что должно лежать и почему, проверенные команды | перед работой с кодом |
| SPEC.md, specs/ | ТЗ: требования Т1… с цитатами, стек, эталон | перед задачей по функциям |
| DECISIONS.md | почему выбрано так | перед сменой подхода |
| TOOLS.md | что установлено, зачем, версия, как удалить | перед установкой |
| FOUNDATION.md | библиотека, темы, каркас, витрина | при работе с интерфейсом |
| previews/ | галерея и превью стилей и макетов | при выборе вида |
| solutions/ | решённые проблемы, по одной на файл | поиском при похожей ошибке |
| archive/ | полные версии до сжатия (`kit-compact`), слова владельца дословно | нужно точно, что он сказал: Grep |
| timing.csv | хронометраж ответов (пишет хук, в git не идёт) | «почему долго», «сколько потрачено» (`kit-timing`) |
| ../../SEARCH.md | чем и где искать: каталоги, реестры, инструменты поиска | перед любым поиском |
