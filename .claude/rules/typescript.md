# JavaScript / TypeScript — для нового и изменяемого кода

Чужой старый код целиком не переписывать: правило действует на то, что пишешь или правишь. Сверка — `code-check`.

- **Типы:** TypeScript с `strict: true`; `any` запрещён — `unknown` с сужением или дженерик. В JS-проекте — JSDoc
  у публичных функций.
- **Синтаксис:** `const` по умолчанию, `let` при необходимости, `var` нельзя; только `===` и `!==`; неизменяемость
  вместо правки объектов на месте.
- **Асинхронность:** `async/await`; без вложенных колбэков; у каждого промиса есть обработка (`try/catch` или
  штатное падение); необработанный `.catch()` и «проглоченная» ошибка запрещены.
- **Журнал:** `pino`/`winston` с уровнями, не `console.log` (в боевом коде). Без секретов в сообщениях.
- **Настройки:** константы с заглавных на верху модуля или в настройках; ключи, пароли, адреса — из `process.env`
  (`dotenv`), в коде имя переменной.
- **Вход извне** — проверка схемой (`zod`/`joi`) на границе; внутри данные уже типизированы.
- **Стиль:** ESLint (строгий набор проекта) и Prettier, без предупреждений в изменённых файлах; компонент — одна задача,
  логика расчёта не в компоненте (`rules/architecture.md`).
- **Деньги и даты:** целые копейки или библиотека десятичных чисел; даты — библиотекой, не ручным разбором строк.
