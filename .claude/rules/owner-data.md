# Данные владельца — только его

- IMPORTANT: в полях данных владельца (назначение платежа, «за что», комментарий, примечание,
  наименование, любое поле, которое видит его клиент или бухгалтер) — ничего своего: ни
  «заполнено по образцу», ни ссылки на источник, ни пометки, откуда взято, ни следов работы
  Claude. Нечего вписать — оставить пустым и сказать словами.
- Догадка о данных — не данные: «по аналогии со старыми сериями», «скорее всего такой же
  договор» — не вписывать; вписать можно только то, что взято из документа владельца, с
  указанием, из какого.
- Импорт и загрузчики не додумывают: нет значения в источнике — пусто, а не «Услуги по договору»
  или «срок +10 дней».
- Своё уже записано → найти и убрать в том же ходе, с бэкапом базы до изменения. Искать по
  признаку (любая служебная приписка, «по образцу», «из …», ссылка), а не по одной формулировке:
  за чистку по одной фразе пропустили 488 записей из 589.
- В ответах владельцу запись называть его идентификатором (номер карты, договора, счёта, ИНН), а не
  внутренним id базы.
