# Выкладка и применение правок

- IMPORTANT: **выложено = сверено на месте назначения**: контрольные суммы файлов в контейнере или
  на сервере равны локальным, либо в файле там виден признак новой правки (`grep -c <новое имя>`).
  Пока такой вывод не показан, слово «выложено» не произносится — ни владельцу, ни в документах.
- «Страницы отвечают 200/302», «в логе ошибок нет», «скрипт отчитался успехом» — не доказательство:
  старый код отвечает ровно так же. Повод: три часа правок ушли «в никуда», скрипт брал файлы из
  папки с прошлого раза, а не из присланного архива.
- Перед заливкой проверить, куда именно смотрит цель: скрипт выкладки — из какой папки берёт и
  распаковывает ли архив сам; контейнер — какую папку монтирует (`docker inspect -f
  '{{range .Mounts}}{{.Source}} → {{.Destination}}{{"\n"}}{{end}}' <имя>`); не «первая по `ls`».
- Правка шаблона, внутри которого `<script>`: после правки — консоль браузера без `SyntaxError` и у
  каждого обработчика на месте его открывающая строка. Потерянная строка ломает весь скрипт
  страницы, а страница при этом отвечает 200.
- Статика подключается с меткой версии (`?v=`), иначе браузер держит старую копию, и проверка
  показывает прошлое.
