# Правила интерфейса
Вёрстка (наезды, размеры, замер) — `layout.md`; копия по образцу и «точь-в-точь» — скилл `clone-screen`.

- Одна библиотека компонентов на проект (`docs/ai/FOUNDATION.md`); тема переключается целиком.
- Цвета, шрифты, размеры, отступы — только из темы (токены / CSS-переменные / классы). «Сырые» значения
  (`#3b82f6`, `13px`) в экранах не писать.
- Экран собирается из компонентов витрины; нужного нет — сначала в витрину, потом использовать.
- Общий стиль (шапка, меню, кнопки, таблицы) меняется в одном общем месте, не копией на экране. Размер и
  положение (`width`, `height`, `margin`, `padding`, `position`, `z-index`, `overflow`, `font-size`) в стиле
  конкретного экрана не пишутся: `grep`, где ещё этот класс → правка в теме или общем классе → снимок до и после
  на каждой странице с этим элементом.
- У экрана есть состояния «загрузка / пусто / ошибка / нет доступа». Тексты интерфейса — русские; имена — латиница.
- Светлая и тёмная тема; ширины — по `layout.md`; после изменений — `ui-checker` (в полной проверке).
- «Так же, как на X» — повторить всё поведение X (курсор, наведение, щелчок, состояния), не только вид; общий
  элемент меняется в том же шаге на всех страницах.
- Утверждение о виде (ширина, отступ, цвет, что куда встало) — только после снимка экрана: код и вёрстка
  не доказательство.
- Обрезка текста — только вид: везде, где текст не влез, его можно прочитать целиком (раскрытие ячейки, `title`).
- Форма открывается с тем, что сохранено: поле с текущим значением, список и переключатель на действующем,
  после сохранения — новое, не сброс; пустое = «значения нет». Секреты не показывать: «сохранён, можно не
  трогать», пустое при сохранении = оставить прежний. Проверка: открыть форму второй раз.
- Мёртвых кнопок не бывает: пункт меню ведёт на живой экран; нужен ключ или деньги — экран объясняет, что
  нужно, и ведёт в настройки. Экран готов, когда работают все кнопки, фильтры, сортировки, проваливания.
- Переписал экран — список элементов до и после (кнопки, формы, ссылки, фильтры): всё старое есть в новом;
  заменил компонент — найти, кто его звал; открыть в браузере, консоль чистая («собралось» не считается).
  Экран переносится целиком или остаётся старый.
- IMPORTANT: **на свой экран смотрит Claude, а не владелец.** В проекте одна команда «снимок экрана» (адрес →
  путь к картинке; вход в тестовую копию сама). После правки вида — запустить и посмотреть до ответа:
  покрашено то и только то, о чём просили, соседнее на месте. Команды нет — собрать первой задачей по
  интерфейсу и вписать в `PROJECT_MAP.md`; нельзя собрать (нет входа, копии) — сказать первой строкой, чего
  не хватает, и описать словами, что изменится. Править вид вслепую и выкладывать на боевой «чтобы владелец
  посмотрел» запрещено; боевой — только по его слову.
- Правка шаблона с `<script>`: консоль браузера без `SyntaxError`, у каждого обработчика на месте открывающая
  строка (потерянная строка ломает весь скрипт, страница отвечает 200). Статика — с меткой версии (`?v=`), иначе
  браузер держит старую копию.
