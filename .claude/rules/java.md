# Java (для нового и изменяемого кода)

Чужой код целиком не переписывать. Сверка — `code-check`; сборка проекта (Maven/Gradle) — его командой из PROJECT_MAP.

- **Слои:** контроллер → сервис → репозиторий; в контроллере нет бизнес-правил и запросов, в репозитории — нет правил.
  Данные между слоями — DTO, сущность БД наружу (в API) не отдавать.
- **Зависимости:** внедрение через конструктор, поля `final`; без статических «синглтонов» и `new` сервисов внутри.
- **Null:** не возвращать `null` из коллекций (пустая коллекция), `Optional` — для результата метода, не для полей и
  аргументов; входные аргументы проверять (`Objects.requireNonNull`, Bean Validation).
- **Ошибки:** конкретные исключения, не `catch (Exception e) {}` и не `printStackTrace()`; журнал через SLF4J с
  контекстом, без секретов; в ответ клиенту — понятное сообщение без stack trace.
- **Ресурсы:** `try-with-resources` для потоков и соединений; транзакция — на уровне сервиса.
- **Деньги и время:** `BigDecimal` (с явным `RoundingMode`), `java.time` (`Instant`/`ZonedDateTime`), не `double`, не `Date`.
- **SQL:** только `PreparedStatement`/параметры JPA, без склейки строк.
- **Стиль:** имена по смыслу, `camelCase`/`PascalCase`/`UPPER_SNAKE`; публичные методы — Javadoc; конкурентный код —
  `java.util.concurrent`, не ручные потоки.
