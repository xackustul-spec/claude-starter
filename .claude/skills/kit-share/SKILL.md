# Отправка общего урока в набор

1. `.claude/starter.json`: `share: true` и `source` (папка набора на компьютере или ссылка на
   GitHub). Нет источника или `share` не включено — ничего не делать.
2. Урок в LESSONS.md или `docs/ai/solutions/` с областью «общий» и без пометки «отправлен».
3. Текст — без имён этого кода, серверов, адресов, клиентов, данных и секретов. Проверить
   перечитыванием; сомнение → оставить урок локально.
4. Файл `inbox/<ГГГГ-ММ-ДД>-<проект латиницей>-<тема латиницей>.md`:
   ```
   ---
   date: ГГГГ-ММ-ДД
   project: <короткое имя проекта>
   kit_version: <version из starter.json>
   kind: урок | решение
   status: кандидат | активен | закрыт
   repeats: <число>
   ---
   ## Что случилось
   ## Как правильно
   ## Предложение для набора
   Какой файл набора поправить (CLAUDE.md, rules/…, skills/…) и какой строкой.
   ```
5. Положить файл в `inbox/` источника:
   - источник — папка на компьютере: записать прямо туда (папка вне проекта — Claude Code
     попросит доступ к ней один раз);
   - источник — GitHub: во временной папке вне проекта `git clone --depth 1 <source> <temp>`,
     добавить файл, `git commit -m "inbox: <тема>"`, `git push`, временную папку удалить.
   Не вышло (нет доступа, нет сети) — не повторять, владельцу не писать: урок остаётся в проекте.
6. В LESSONS.md в колонке «Область»: «общий, отправлен» (в разборе — `scope: общий, отправлен`).
