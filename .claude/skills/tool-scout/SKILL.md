# Подбор инструментов: $ARGUMENTS

Только под реальную потребность проекта. Стартовые наборы по типам проектов —
[packs.md](packs.md); где искать и кому верить — [sources.md](sources.md).

## 1. Запрос
Что именно нужно, в каком стеке, ограничения (бесплатно/платно, локально/облако,
персональные данные). Пример: «сжатие видео для фона сайта на Next.js, локально, бесплатно».
Сначала базовый набор из packs.md (git, безопасность, LSP языка, браузер для проверки,
Context7), потом специальное.

## 2. Искать в порядке доверия
1. Уже установленное (docs/ai/TOOLS.md, `.mcp.json`; `claude mcp list`, если есть терминал;
   `/mcp`, `/plugin` — просить владельца).
2. Официальные Anthropic: каталог плагинов, `anthropics/skills`, коннекторы.
3. Проверенные: `anthropics/claude-plugins-community`, skills.sh (`npx skills find …`),
   GitHub MCP Registry, Docker MCP, awesome-списки; скиллы авторов библиотек.
4. Официальный реестр MCP. 5. Большие агрегаторы — только с чтением кода.
6. Обычная библиотека (npm, PyPI) через Context7 — часто задачу решает она, а не скилл.

## 3. Оценить и проверить безопасность (обязательно)
| Критерий | Как |
|---|---|
| Автор | официальный / автор библиотеки / неизвестный (имя «похоже на официальное» ≠ официальное) |
| Жизнь | установки, звёзды, дата обновления |
| Что ставит | плагин — вкладка деталей (скиллы, хуки, MCP, стоимость контекста); скилл — прочитать все файлы, включая скрипты и тесты (`*.test.*`, `conftest.py` запускаются тест-раннером) |
| Опасные признаки | сетевые запросы, base64, скачивание программ, чтение `.env`/ключей, действия вне заявленной цели, скачивание при работе |
| Пакеты | существует давно, есть история и репозиторий — модели придумывают имена, злоумышленники их регистрируют |
| Совместимость | `compat-check` |
| Цена, контекст | бесплатно / ключ / тариф; постоянные описания — чем меньше, тем лучше |
MCP — минимум прав, без записи в рабочие базы; описания инструментов MCP могут меняться
после подключения — перепроверять при обновлении. Меньше ~100 установок и неизвестный
автор — только после чтения кода и с предупреждением. Сканер `mcp-scan` (через `uvx`, версию прибить) — по желанию.

## 4. Предложить → «да» → установить → записать
Таблица: возможность → 1–3 кандидата → рекомендация → что установится и куда → как удалить.
После «да» (при полном доверии — сам): установить ровно одобренное, пробная задача,
строка в TOOLS.md; отклонённые — в «Рассмотрено и отклонено». Два инструмента на одно
и то же не ставить; фреймворков процесса — не больше одного; неиспользуемое — предложить убрать.
