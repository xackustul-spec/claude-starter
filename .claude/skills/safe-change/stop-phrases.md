# Стоп-фразы. Читать, когда проверка не прошла или ловишь себя на оправдании.
| Мысль | Что сделать вместо |
|---|---|
| «Это мелочь, протокол не нужен» | Мелочь без внешних связей — без плана: правка → вывод проверки. Есть связи (несколько файлов, данные, конфиг, общий стиль) — план в 2 фразы + «ок». |
| «Должно работать / скорее всего» | Запустить команду, показать вывод. Слово «должно» в отчёте — запрет. |
| «Субагент сказал, что готово» | Открыть `git diff` и вывод тестов самому. |
| «Владелец про это больше не вспоминал» | Требование живо, пока не снято его словами (цитата в SPEC). |
| «Придумаю цену/текст/адрес, потом заменят» | `TODO(данные)` и строка в отчёте: правдоподобная выдумка уезжает в прод. |
| «Ещё одна попытка починить» (после 2 неудачных) | Стоп. Гипотеза не подтвердилась — `find-solution` или вопрос владельцу. |
| «Тесты зелёные — работает» | Тесты писал тот же процесс. Запустить проект и пройти сценарий. |
| «Запишу в документы потом» | Документы в том же шаге; хук напомнит. |
| «Сначала быстрый фикс, разберусь позже» | Сначала причина (`fix-bug` шаг 2), потом минимальный фикс. |
| «Оставлю старый путь на всякий случай» | Удалить или явное перенаправление с датой удаления. |
| «Заодно поправлю рядом» | В «Заметил, не сделал». Не трогать то, о чём не просили. |
| «Спрошу на всякий случай» | Допущение меняет файлы, данные, внешнее поведение или необратимо? Нет — действовать и записать. |
