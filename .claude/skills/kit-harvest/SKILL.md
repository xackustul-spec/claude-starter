# Сбор уроков в набор

Работать только в папке набора (в корне есть `INSTALL.md` и `VERSION`). Репозиторий — сначала `git pull`.

1. Собрать файлы `inbox/*.md` (кроме README). Пусто — сказать владельцу и остановиться.
2. Объединить одинаковые по смыслу. Для каждой темы: сколько проектов, статус (активен и
   закрыт — весомее кандидата), каких файлов набора касается.
3. Фильтр: правило верно для любого проекта; не противоречит CLAUDE.md и правилам; не
   раздувает ядро (в CLAUDE.md — только то, что нужно в любой задаче, остальное — rules или
   скиллы); лучше хук или тест, чем текст. Уже есть в наборе → только уточнить формулировку.
4. Показать владельцу таблицу: тема → откуда (сколько проектов) → что изменить и где →
   «Рекомендую: принять / отклонить». Получить «да» по каждой строке или разом.
5. Внести принятое. Хуки менять одинаково в `kit_hooks.py` и `kit_common.ps1`, добавить
   случай в `tests/cases.json`. Прогнать `python3 .claude/hooks/tests/run_tests.py`.
6. Разобранные файлы из `inbox/` удалить (отклонённые — тоже, причину — строкой в CHANGELOG).
   `VERSION` +0.1 (правила) или +0.0.1 (формулировки), строка в `CHANGELOG.md`.
7. Коммит `release: <версия>`; репозиторий — `git push`. Проекты увидят версию в течение суток
   (папка-источник — при следующем сеансе).
