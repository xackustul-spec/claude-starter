# Установка claude-starter — инструкция для Claude

Владелец дал ссылку на этот набор (или положил его в папку проекта) и просит установить.
Выполни всё в этом же разговоре, не отправляя владельца вводить команды.

1. Сначала — та ли папка: набор ставится в папку одного проекта, а не в общую (`C:\Claude`,
   `Documents`, домашняя папка). Не похоже на проект — спросить владельца, какой проект и где
   он лежит; для нового проекта предложить создать папку с именем латиницей.
2. Владелец указал папку набора на этом компьютере (например `C:\claude-starter`) → скопировать
   её содержимое в подпапку `_starter` (без `.git`). Источник — эта папка.
   Дал ссылку, набора ещё нет в проекте → скачать в подпапку `_starter`:
   `git clone --depth 1 <ссылка на репозиторий> _starter`, затем удалить `_starter/.git`.
   Нет git → скачать архив `<ссылка>/archive/refs/heads/main.zip`, распаковать содержимое в `_starter`.
   Приватный репозиторий без доступа → сказать владельцу, что нужен доступ или публичная ссылка.
3. Запомнить ссылку или папку — это источник обновлений (запишется в `.claude/starter.json`).
   Прочитать `_starter/.claude/skills/kit-setup/SKILL.md` и выполнить его целиком: он перенесёт
   набор в корень, не заменяя файлы владельца, спросит профиль, проверит, закоммитит и
   перейдёт к разбору нового проекта или подключению работающего.
4. Вопросы владельцу — только там, где это требует скилл (что затронет его файлы, профиль).
